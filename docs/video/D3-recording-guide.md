# D3 录屏执行手册（3 分钟 / 5 分钟 / 离线兜底）

> 这份文件只解决一件事：**让录制变成机械活**。每一段写清「时间码 · 屏幕上该是什么 · 手该点什么 · 旁白说什么」。
> 配套字幕：`subtitles-3min.srt`、`subtitles-5min.srt`（可直接拖进剪辑软件烧字）。
> 前置依赖：C9 镜单（#33）。**若 C9 出来后与本文冲突，以 C9 为准**，本文随之改，不并存两套。

## 0. 录制前的一次性准备

| 项 | 建议值 | 说明 |
| --- | --- | --- |
| 分辨率 | 1920×1080 录制，页面窗口 1440 宽 | 页面两栏在 1440 下最舒服；1080p 够清晰又不至于字太小 |
| 浏览器缩放 | 100% | 缩放到 110% 会让右栏「证据清单」换行 |
| 终端字号 | 16px 以上 | 评委要看 `verify.sh` 的 `PASS` 那行 |
| 录制工具 | OBS / Windows Xbox Game Bar / QuickTime | 30fps 即可，不需要 60 |
| 鼠标 | 开启点击高亮 | 评委要跟得上点在哪 |
| 数据 | 先清库再 seed：`rm -f data/medpal.db && rm -rf data/reports && python -m app.seed` | 否则 `/v1/assets` 会有重复资产，画面里 ID 会跳 |

### 起服务（三个版本共用这一步，只有 host 不同）

```bash
# 本地版 / 离线版
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
# 线上版：把 8000 换成 APIG 域名（需 B10/B11 就绪，见 §5）
```

浏览器打开 `http://127.0.0.1:8000/web/`。

## 1. 三分钟版（180 秒，主线只讲一件事：可追溯）

| # | 时间码 | 屏幕画面 | 操作 | 旁白要点（字幕同文） |
| --- | --- | --- | --- | --- |
| 1 | 00:00–00:12 | 演示页首屏（标题 + 一句话） | 静止 | 这是「可追溯的医疗知识底座」，不是聊天机器人。 |
| 2 | 00:12–00:30 | 终端 | 敲起服务命令 | 一条命令起服务：SQLite + BM25 + 离线模型，零云依赖也能跑。 |
| 3 | 00:30–00:45 | 页面默认态 | 点输入框里的示例问句的「提问」 | 问一句：上腹隐痛伴反酸，下一步做什么检查？ |
| 4 | 00:45–01:00 | 左上结论卡 | 静止，鼠标划到「科室 / 检查 / 相关用药」 | 结论给出科室、检查、相关用药；右上完整率 100%、证据 8 条。 |
| 5 | 01:00–01:15 | 右下证据清单 | 点第一行「展开 ▾」 | 每条证据都能点回原文锚点——看，这是原句。 |
| 6 | 01:15–01:30 | 左侧决策链 | 点第 1 步 `retrieve` | 决策链 6 步，点某一步，右侧对应证据会高亮。 |
| 7 | 01:30–01:45 | 拒答态 | 地址栏切 `?demo=refusal` | 本体里没有路径的问题，它不编，直接说「不能回答」并列出缺口。 |
| 8 | 01:45–02:05 | 假锚点 0% 红屏 | 地址栏切 `?trace=<假锚点trace>` | 把证据换成不存在的锚点：完整率立刻掉到 0%，证据区整块标红——这个数不是画的。 |
| 9 | 02:05–02:30 | 终端 | 跑 `bash scripts/verify.sh` | 一键验收 7 项全绿；评测 60 条，科室准确率 0.967。 |
| 10 | 02:30–03:00 | 回到页面首屏 | 静止 | 换行业只换词表，换云只换插槽；仓库和命令都在 README 里。 |

**三分钟版必须出现的高光瞬间**：第 5 段（点出原文）、第 8 段（0% 标红）。这两处是「可追溯不是口号」的唯一证据，别剪掉。

时间码 00:00–03:00 与三分钟版**完全一致**（可直接复用同一段素材），从 03:00 起加四段：

| # | 时间码 | 屏幕画面 | 操作 | 旁白要点 |
| --- | --- | --- | --- | --- |
| 11 | 03:00–03:30 | 加载态固定画面 | 地址栏切 `?demo=loading` | 加载态是骨架屏，不发真实请求，录屏时画面不会自己变。 |

| 15 | 04:50–05:00 | 契约校验终端 | 跑「回读 trace + validate」 | 决策链过冻结契约校验，`contract_errors=[]`；结论到此收尾。 |

> ```bash

> from medpal_core.contracts.trace import load_schema
> from medpal_core.contracts.trace.validator import validate
> print('contract_errors=', validate(json.load(sys.stdin), load_schema()))"
> ```

## 3. 离线兜底版（断网也要能放）

**为什么需要**：答辩现场网络不可控。整套系统默认就是离线形态（`MEDPAL_LLM=offline`、SQLite、BM25），所以断网照放。

录制/演示要点：

1. 起服务前确认没有云变量：`env | grep -i huawei` 应为空；
2. 断网（拔网线或关 Wi-Fi）后重放上面 1–10 段——**行为完全一致**，因为一次外网请求都没有；
3. 唯一差异：`/v1/cloud` 会显示四项 `ready` 全 `false`，`missing` 列出缺的变量名。**这不是故障，是如实上报**——讲解时直接说「没配就说没配」。

> 如果现场需要证明「真断网」，可以在录屏开头录一下任务栏网络图标为断开状态。

## 7. 已知风险（录之前先排掉）

| 风险 | 症状 | 规避 |
| --- | --- | --- |
| 库里有历史 trace 导致 ID 撞号 | 页面报错、终端 `UNIQUE constraint failed` | 录制前清库重 seed（§0 已写） |
| 端口被占 | 起服务失败或打到旧进程 | 换 `--port 8001`，或先查占用 |
| 浏览器缓存了旧页面 | 三个 `?demo=` 入口点了没反应 | 硬刷新（Ctrl+Shift+R） |
| 字号太小评委看不清 | 终端 `PASS` 那行糊 | 终端字号 16px+，录制 1080p |
