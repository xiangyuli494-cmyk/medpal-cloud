## 完成定义（DoD）——五条全满足才算 Done

1. 分支从最新 `main` 切出，PR 标题带任务编号，diff ≤ 400 行；
2. CI 全绿（ruff / 边界 / 禁用语 / pytest 3.11+3.12 / PR 元信息）；
3. **已有 1 人 approve**（另一条 lane 的人），由队长 t1 合并进 `main`；
4. 有对应测试或 smoke 脚本，且能在**离线**状态跑通（`bash tools/dev.sh all`）；
5. 文档同步 + 演示主路径没被破坏（演示页三条路径仍可一键触发）。

> 注意：**「代码写完」不等于 Done**。没进 `main` 的都不算交付，也就没法写进方案书截图。
> 提 PR 前先在本地跑 `make pr`（= lint + check + test，约 20 秒），别让 CI 替你发现低级错误。
