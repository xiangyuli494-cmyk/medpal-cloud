# 华为云映射：五个插槽，逐条对到代码

原则：**云能力是可替换实现，不是前置条件**。任何一条没配，系统回落本地并明确报告缺口。

## 1. 模型 — ModelArts Studio / 盘古

- 代码：`packages/core/medpal_core/providers/huawei/modelarts.py`（复用 `llm/openai_compatible.py`）
- 变量：`MEDPAL_LLM=openai`、`MEDPAL_LLM_BASE_URL`、`MEDPAL_LLM_MODEL`、`MEDPAL_LLM_API_KEY`
- 端点：`https://api.modelarts-maas.com/v1`（MaaS 是**独立公网域名**，不是 region 端点；`https://modelarts.<region>.myhuaweicloud.com/v1/{pid}/maas/*` 一律 404，别拼）
- 鉴权：MaaS 用**独立 API Key**，不是 AK/SK。代码取值顺序 `MEDPAL_LLM_API_KEY` > `HUAWEI_MODEL_API_KEY` > `HUAWEI_AK`
- 用途：把「结论草稿 + 证据」渲染成人话叙述（`conclusion.narrative`），**不给它编造空间**：
  证据由检索与本体提供，模型只做表达。
- 为什么选它：ModelArts Studio 提供 OpenAI 兼容端点，团队不需要为每家模型写一套 SDK。
- 通没通怎么验：`python scripts/smoke_llm.py --strict`（退出 0 才算通）；实测证据见 `docs/evidence/2026-11-08-maas.md`

## 2. 存储 — GaussDB(for openGauss)

- 代码：`providers/huawei/gaussdb.py`；schema 与 `storage/db.py` 的 `SCHEMA` 同源
- 变量：`HUAWEI_GAUSSDB_DSN`
- 迁移方式：`gaussdb.prepare(conn)` 把 sqlite 方言翻成 GaussDB 方言后建表，SQL 语句不变。
- 为什么选它：资产/三元组/决策链是关系型强一致数据，需要事务与唯一约束，不需要 NoSQL 的弹性。

## 3. 对象存储 — OBS

- 代码：`providers/huawei/obs.py`
- 变量：`HUAWEI_AK`、`HUAWEI_SK`、`HUAWEI_OBS_BUCKET`、`HUAWEI_REGION`
- 用途：原件（PDF/图片）与决策链报告 `reports/TR-*.md` 落桶，库里只存 `obs://bucket/key`。
- SDK：`esdk-obs-python`（可选依赖 `.[huawei]`），未装时 `ProviderNotConfigured` 并给出 pip 命令。

## 4. 检索 — KooSearch

- 代码：`providers/huawei/koosearch.py`（实现 `Retriever` 协议）
- 变量：`HUAWEI_KOOSEARCH_ENDPOINT`
- 切换：`build_retriever(conn, kind="koosearch")`
- 为什么选它：锚点文本是长尾专业语料，向量/混合检索比 BM25 稳；接口一致所以评测口径不变。

## 5. 计算与网关 — FunctionGraph / CCE + APIG

- 形态一（省事）：镜像推 SWR → CCE Deployment → APIG 挂 `/v1/*`，演示期用。
- 形态二（讲故事）：`/v1/ask` 走 FunctionGraph 弹性，冷启动可接受，按调用计费。
- 健康检查：`GET /health` 返回本体版本、资产数、当前模型后端，APIG 可直接探活。

## 6. 部署清单（骨架，待补 Terraform / 脚本）

1. 建 OBS 桶 + GaussDB 实例，跑 `gaussdb.prepare`。
2. 开 ModelArts Studio 推理服务，记下 endpoint 与模型名。
3. 建 KooSearch 实例，导入 `data/samples` 语料。
4. 构镜像（`Dockerfile` 已在仓库根：`docker build -t medpal-trace:0.1.0 .`）→ SWR → CCE。
5. APIG 绑定域名 + 限流；`MEDPAL_DATA_DIR` 指向挂载卷。
6. 冒烟：`GET /health` → `POST /v1/ask` → `GET /v1/traces/{id}`。

> `Dockerfile` 已落地（内置 PYTHONPATH，容器内直接 `uvicorn app.main:app`）；仍未落地的是 Terraform 与
> `scripts/dev_pg.sh` 这类部署脚本，属于路线图第 2 阶段（见 docs/04）。
