# 演示页 v2 线框（A4）

> 目标：一屏讲清「结论 — 证据 — 完整率」，并且**默认 / 加载 / 拒答**三态都能演示。
> 交付位置：`apps/web/index.html`（单文件、无构建、无外部依赖），本文件只定线框与交互。
> 依赖的接口：`POST /v1/ask`、`GET /v1/traces/{trace_id}`、`GET /v1/assets/{asset_id}`（A3）、
> `GET /v1/ontology/versions`（A3）。三个 GET 都已在 main 或 A3 分支就绪。

## 0. 与 v1 的关系

- v1 已有：输入框、结论、完整率进度条、决策链表格、缺口列表。
- v2 只补三件事：**证据可展开**、**三态可切换**、**数字口径可见**（证据数 / 未核对 / 本体版本）。
- 不做：路由、前端框架、登录、多轮对话、图表库。

**交互热点**

| 编号 | 元素 | 行为 |
| --- | --- | --- |
| H1 | 本体版本徽标 | 点击按 `GET /v1/ontology/versions` 展示最近 3 个版本（version / triple_count / is_current） |
| H2 | 输入框 + 提问 | Enter 或点「提问」提交；空输入禁用按钮；提交后进入加载态 |
| H3 | 完整率数值 | `≥0.8` 绿、`0.5–0.8` 黄、`<0.5` 红；低于 1.0 时数字旁标「未核对 N 条」 |
| H4 | 进度条 | hover 显示「已核对 / 未核对」；点击展开 `unresolved` 列表 |
| H5 | 决策链某一步 | 点击高亮该步 `evidence` 对应的证据行；`ref` 值显示在步骤右侧（PARSE / EVIDENCE / STORE / TRAVERSE / CONCLUDE） |
| H6 | 证据行「展开 ▾」 | 调 `GET /v1/assets/{asset_id}`，在返回的 anchors 里按 `anchor_id` 找原文，展开 2–4 行；找不到显示「锚点不存在（unresolved）」并标红 |

```
┌───────────────────────────────────────────────────────────────────────────┐
│ [ 上腹隐痛伴反酸，下一步做什么检查？                      ] [ 提问中… ]   │
├──────────────────────────────────┬────────────────────────────────────────┤
│ 结论                              │ 溯源完整率                 —            │
│ ████████████████░░░░░░░░░░░░      │ ████████░░░░░░░░░░░░░░░░░░░░░░░░       │ H7
│ ██████████████░░░░░░░░            │ 证据 — 条 · 未核对 — 条                │
├──────────────────────────────────┼────────────────────────────────────────┤
│ 决策链                            │ 证据清单                               │
│ ████████████░░░░░░                │ ██████████████████░░░░░░                │
```

- H7：骨架屏只做 CSS 动画，不用第三方库；输入框禁用；
- 超过 8 秒仍在加载 → 在结论区显示「还在查，最多等 20 秒」；超过 20 秒转错误态。

## 3. 拒答态（`refusal=true` 或 `gaps` 非空且无证据）

```
┌───────────────────────────────────────────────────────────────────────────┐
│ 结论                                                        [复制复现命令] │
│ ┌───────────────────────────────────────────────────────────────────────┐ │
│ │ 这个问题我不能回答。                                                   │ │
│ │ 建议：叫护士 / 换个问法（下面有缺口说明）                              │ │
│ └───────────────────────────────────────────────────────────────────────┘ │ H8
│ 缺口（gaps）                                                              │
│ - 本体里没有可用的推理路径，建议补充三元组或换问法                        │ H9
│ - 识别到的实体：上腹隐痛（未归一到标准节点）                              │
├───────────────────────────────────────────────────────────────────────────┤
│ 溯源完整率：—（无引用，不计分）   证据：0 条                               │
└───────────────────────────────────────────────────────────────────────────┘
```

- H8：拒答卡用灰色底 + 黄色左边框（不出现任何未经验证的结论文字）；
- H9：`gaps` 逐条列出；`unresolved` 实体单独一行；
- 「复制复现命令」按钮：从 `GET /v1/traces/{id}` 或报告里取 curl 段（C6 交付后可用），没有就隐藏按钮；
- 拒答态仍保留完整 trace 链接，评委可点进去看决策链。

## 4. 状态机

```
idle ──提交──▶ loading ──200 且 refusal=false──▶ default（有结论）
                  │  └──200 且 refusal=true / 无证据──▶ refusal
                  └──网络错误 / 5xx / 20s 超时──▶ error（显示「没连上网，我再说一遍」+ 重试）
```

错误态只给一句人话 + 一个「重试」按钮，不显示错误码；详细错误放 `<details>` 里给答辩用。

## 5. 字段映射（实现时照这张表取数）

| UI 元素 | 数据来源 |
| --- | --- |
| 结论 statement / dept / exams / drugs | `POST /v1/ask` → `conclusion` |
| 完整率、证据数、未核对数 | `trace_completeness`、`evidence_count`、`unresolved` |
| 决策链 6 步（op / out / evidence / ref） | `GET /v1/traces/{id}` → `steps[]` |
| 证据展开原文 | `GET /v1/assets/{asset_id}` → `item.anchors[]` 按 `anchor_id` 匹配 |
| 版本徽标 | `GET /v1/ontology/versions` → `items[0]` |
| 拒答与缺口 | `refusal`、`gaps`、`unresolved` |

> 注意：`unresolved` 是「写进证据但核对不到」的项；`gaps` 是「推理链自己承认的缺口」。两者在 UI 上分开显示，别混成一类。

## 6. A6 / A8 验收对齐

- A6：点证据能展开锚点原文；把 `evidence` 人为改成假锚点后，`trace_completeness` 显示 0，且证据区整块标红（红底 + 「未核对」标签）。
- A8：三条演示路径（默认 / 加载 / 拒答）各有一个一键触发入口（可用 URL 参数 `?demo=default|loading|refusal`，不引入路由）。
- 窄屏 375px：左右两栏改为上下堆叠，证据展开不遮挡输入框。

## 7. 实现约束

- 单文件 `apps/web/index.html`；无构建、无外部 JS/CSS 依赖；
- 颜色只用现有 CSS 变量，不新引品牌色；
- 只读 API，不写库；演示数据全部为自拟合成样本，不出现真实患者信息；
- 所有文案遵守「动词 + 方位 + 数量」，不出现抽象术语。
