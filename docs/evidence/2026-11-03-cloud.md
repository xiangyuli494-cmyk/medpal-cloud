## 3. 公网访问用完即关

| 动作 | 位置 | 为什么 |
| --- | --- | --- |
| 解绑 EIP | RDS 实例详情 → 连接管理 → 公网访问 → 解绑 | 不再需要外网入口 |
| 释放 EIP | 弹性公网IP 控制台 → 释放 | 只解绑不释放，IP 保有费照收 |
| 停止实例 | RDS 实例列表 → 停止 | 停机只收存储费，一天几分钱 |

同时把 .env.local 里的 MEDPAL_DB_DSN 注释掉，避免下次误连。
